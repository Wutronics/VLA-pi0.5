# D3 实机安全检查清单

任何会产生机械臂动作的测试都必须由现场人员逐项确认。

## 首次运动前

- [ ] 交付机型确认为 D3，记录控制器固件、`carm` 版本和机械臂序列配置。
- [ ] 操作者能触达硬件急停，且已在不带负载状态验证急停和恢复流程。
- [ ] 软件 `task_stop`/`emergency_stop` 路径经独立进程验证。
- [ ] 左臂伺服或动作通道被禁用；策略动作空间不包含左臂字段。
- [ ] 删除/绕过供应商示例中的构造时自动 `set_ready()` 和双臂硬编码复位。
- [ ] 关节顺序、单位、零位、软限位、速度/加速度限制和夹爪范围已由实际读数确认。
- [ ] 工作空间清场，D3 固定，相机/工具/药盒工装牢固，人员站位明确。
- [ ] 通信断开、动作超时、外骨骼失跟踪和进程退出均进入停止或安全保持。
- [ ] 日志记录实际发送动作、实际反馈、时间戳、错误码和停止原因。

## 每次采集前

- [ ] 配置、标定和任务版本已记录，且与本次场景一致。
- [ ] 相机名称、画面方向、曝光、分辨率和时间戳正常。
- [ ] 外骨骼中立姿态、坐标轴、比例、死区和夹爪映射通过小幅 dry-run。
- [ ] 左臂无动作，右臂命令默认关闭。
- [ ] 先运行只读状态采集，再进行低速空载测试。
- [ ] 现场监护人和中止口令明确。

## 策略上机前

- [ ] checkpoint、训练数据版本、特征 schema 和归一化统计可追溯。
- [ ] 离线回放已验证所有预测动作均在硬限位和项目安全限位内。
- [ ] 相机字段、状态字段和动作字段与训练时完全一致。
- [ ] 推理超时、网络中断和异常输出（NaN/Inf/维度错误）会阻止动作下发。
- [ ] 首次评测使用最低速度、空旷工位、单次短 episode 和人工逐次授权。

未勾选的阻断项不得以“先试一下”跳过。
