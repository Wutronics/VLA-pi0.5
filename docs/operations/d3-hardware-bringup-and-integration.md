# CVTE D3 开箱、硬件集成与首次连通指南

更新日期：2026-11-13

适用范围：CVTE/视源 D3 固定式双臂机器人，当前交付状态为已有机器人本体、尚未安装夹爪、腕部相机和正式稳定底座。

本文汇总当前阶段已经核对的产品手册、官方代码、官方仿真模型和交付装配体信息，用于指导底座加工、夹爪与腕部相机采购、网络连接及首次上电联调。它不能替代现场风险评估和交付版本的厂商确认。

## 1. 当前结论

| 项目 | 当前结论 | 置信度/处理方式 |
| --- | --- | --- |
| 原配夹爪 | CVTE/CARM 自研平行夹爪，软件模型名 `carm_gripper`；未公开独立商业型号 | 已由官方代码与模型确认 |
| 夹爪驱动 | 官方 `carm_tool` 使用达妙 `DM4310` 作为内部执行电机 | 电机型号不是完整夹爪采购型号 |
| 末端机械接口 | 法兰有 3 个 M4 螺纹孔，快拆件由 3 颗 M4 螺丝锁紧 | D3 产品手册 V0.6 明确说明 |
| 底座外形 | `120 × 120 mm` | D3 产品手册尺寸图 |
| 底座安装孔 | 4 个 `Ø6.6 mm` 通孔，孔中心距 `105 × 105 mm` | 产品手册尺寸图与当前装配体一致 |
| 底座螺栓 | 使用 M6 螺栓；稳定座若攻牙则为 `M6 × 1.0` | `Ø6.6` 是 M6 普通间隙孔；手册正文的“M6.4螺栓”视为标注错误 |
| 腕部相机 | 官方抓取示例支持 Orbbec Gemini 305 和 Intel RealSense D405 | 已由 `carm_grasp` 确认 |
| 相机数据接口 | USB 3.0；D3 底部 USB-A 3.0 可连接相机或其他 USB 设备 | 产品手册明确说明 |
| 千兆网口 | 连接开发机或外部控制单元，访问 Web 上位机及 SDK/ROS 控制通信 | 不是光纤口、USB口或已声明的 PoE 口 |
| 首次开发连接 | 开发机与 D3 用 CAT5e/CAT6 网线直连 | 最易排障、延迟和稳定性最好 |
| 局域网开发 | 可以；D3 仍需通过网线接入路由器/交换机，开发机可走 Wi-Fi 或网线 | 不建议公共网络或 Wi-Fi 承担安全功能 |

## 2. 仍需采购或向供应商确认的物料

### 2.1 必需物料

- 可靠固定到底板、工作台或地面的稳定座。
- 4 颗合适长度的 M6 高强度螺栓、平垫圈及防松措施。
- D3 原厂左、右夹爪总成，包括快拆件、末端线束和紧固件。
- 两台腕部 RGB-D 相机，推荐两台同型号 Gemini 305 或 D405。
- 两套刚性腕部相机支架。
- 短、柔软、耐弯折的 USB 3.0 线和线束固定件。
- 双相机共用时的带独立供电 USB 3.0 Hub。

### 2.2 必须向供应商索取的信息

- 夹爪总成的正式料号、左右件区分和装配视频。
- 末端电气接口针脚定义、线束料号和固件兼容表。
- 工具坐标/TCP、工具质量和质心参数。
- 夹爪零位、开口范围、闭合力和标定流程。
- 腕部相机支架的 STEP/STL 文件及推荐安装方向。
- 交付控制器、固件、Web 上位机和 `carm` SDK 的版本组合。

不要把 `DM4310` 当作可直接采购安装的完整夹爪，也不要根据外观购买 Robotiq、因时、大寰等通用夹爪直接替代；机械、电气、CAN 地址和软件工具类型均可能不兼容。

## 3. 夹爪型号和装配

### 3.1 型号与软件量程

公开资料只给出 `carm_gripper`/CARM 自研平行夹爪，没有给出独立商业型号。官方 D3 MuJoCo 模型中每侧夹指滑动行程约 `37 mm`，对应总开口约 `74 mm`；官方工具驱动配置中开口量程约为 `0–77 mm`。这些数值可作为软件初始参考，但必须以交付夹爪实测和标定结果为准。

### 3.2 机械安装

1. 关闭机器人和电源组件，按下实体急停，并托住腕部。
2. 区分左、右夹爪及安装朝向。
3. 检查末端法兰的 3 个 M4 螺纹孔、快拆件和线束接口是否完好。
4. 将夹爪快拆件与法兰定位面对齐。
5. 夹爪开合方向应与水平线平行；螺丝和插口所在方向朝上。
6. 使用 3 颗 M4 螺丝均匀锁紧，不允许缺少任意一颗。
7. 用原厂夹爪线连接夹爪电机和末端接口；插头无法插入时不要强压，应核对插头方向。
8. 固定线束并验证 J5–J7 全行程内不拉扯、不卷入关节。

### 3.3 软件配置与验证

1. 无夹爪阶段，左右末端工具保持“无工具/工具编号 0”。
2. 安装原厂夹爪后，把对应末端工具设置为夹爪/工具编号 1。
3. 双臂装配或更换工具后重启机器人。
4. 先检查左右末端执行器类型和连接状态。
5. 在最低速度、空载条件下分别执行一次小幅开合。
6. 完成零位、最大开口和闭合力标定后再夹持物体。

公开资料未给出可安全自行制作的末端电气针脚定义，禁止猜测供电或 CAN 接线。

## 4. 稳定座设计与安装孔

### 4.1 已确认尺寸

产品手册 V0.6 的底座尺寸图和当前交付装配体测量结果一致：

```text
底座外形：120 × 120 mm
安装孔：4 × Ø6.6 mm 通孔
横向孔中心距：105 mm
纵向孔中心距：105 mm
对应螺栓：M6
```

相对底座中心的孔中心坐标为：

```text
(+52.5, +52.5) mm
(+52.5, -52.5) mm
(-52.5, +52.5) mm
(-52.5, -52.5) mm
```

稳定座有两种常见做法：

- 攻牙安装：4 个 `M6 × 1.0` 螺纹孔。
- 贯穿安装：4 个 `Ø6.6–7.0 mm` 通孔，配 M6 螺栓、垫圈和防松螺母。

手册正文写有“4 颗 M6.4 螺栓”，但同页尺寸图明确标注 `4-Ø6.6贯穿`。标准紧固件中应按 M6 螺栓理解，`6.4` 不应作为螺纹公称规格加工。

### 4.2 版本差异说明

早期公开仿真 STL 的几何反算曾得到其他孔组或孔距，不能作为当前交付机的加工依据。当前优先级为：

1. 交付实物卡尺测量；
2. 产品手册 V0.6 尺寸图；
3. 当前装配体文件；
4. 公开仿真 STL 仅作外观和运动学参考。

正式加工前仍应在实物上复核 `Ø6.6`、`105 × 105 mm` 和 `120 × 120 mm` 三项尺寸。

### 4.3 稳定性要求

D3 自重约 `19.7 kg`，单臂额定负载 `3 kg`，工作半径约 `862 mm`。稳定座不应仅依靠一块小型配重板自由放置，应固定到钢制工作台、刚性框架或地面。首次运动前检查底座与安装面完全贴合、四颗螺栓均匀锁紧且有防松措施。

## 5. 腕部相机方案

### 5.1 相机选择

官方 `carm_grasp` 示例支持：

- Orbbec Gemini 305 RGB-D 相机；
- Intel RealSense D405 RGB-D 相机。

Gemini 305 与官方安装照片和示例配置更接近；D405 适合近距离眼在手任务且驱动生态成熟。左右腕优先使用同型号相机，便于统一标定和数据规格。

### 5.2 推荐连接拓扑

本项目推荐把双腕相机接到外部视觉/开发机：

```text
左腕相机 ─┐
           ├─ 带独立供电的 USB 3.0 Hub ── 开发机
右腕相机 ─┘                              │
                                         │ CAT5e/CAT6
                                         ▼
                                     D3 千兆网口
```

优点：

- 相机驱动、录制、点云和 VLA 模型直接运行在开发机；
- 不依赖 D3 内置 Linux 的登录权限和软件环境；
- 更容易固定相机序列号、分辨率、帧率和时间戳；
- 原始图像无需先进入 D3 再经网络转发。

D3 底部 USB-A 3.0 也可连接相机。如果选择相机接 D3 内置算力，必须先确认内置系统登录权限、相机驱动、USB供电与带宽，并在 D3 内部启动驱动；外部开发机不会自动把该设备识别为本机 USB 相机。

### 5.3 机械安装与布线

- 相机固定在夹爪基座/末端固定框架上，不固定在活动夹指上。
- 相机光轴朝向两夹指之间的抓取区域。
- 官方示例要求相机 Z 轴与工具 Z 轴夹角小于 `45°`。
- 夹爪最大开口时不能严重遮挡深度视野。
- 使用弯头、短而柔软的 USB 3.0 线，并在相机附近设置应力释放点。
- J7 附近预留活动线环，但线缆不能进入关节缝隙。
- 以最低速度分别测试 J5、J6、J7 全行程，确认不拉扯、不缠绕。

### 5.4 驱动、命名和标定

- Gemini 305：使用 `OrbbecSDK_ROS2`。
- D405：使用 `realsense-ros`。
- 使用设备序列号固定左右身份，不依赖 `/dev/video0` 等临时编号。
- 建议命名空间为 `/left_wrist/...` 和 `/right_wrist/...`。
- 左右腕分别完成相机内参检查和眼在手 `AX=XB` 标定。
- 每侧采集包含平移和旋转变化的约 15–25 个标定姿态。
- 再标定夹爪中心、指尖位置和抓取宽度。
- 相机或支架移动后必须重新进行该侧手眼标定。

官方单相机示例话题：

```text
Gemini 305:
  /gemini305/color/image_raw
  /gemini305/depth/image_raw

RealSense D405:
  /realsense/d405/color/image_rect_raw
  /realsense/d405/aligned_depth_to_color/image_raw
```

## 6. 千兆网口、直连和局域网开发

### 6.1 接口用途

D3 底部 RJ45 是普通千兆铜缆以太网口，用于连接开发机或外部控制单元、访问 Web 上位机以及使用 SDK/ROS 通信。它不是光纤口，也没有资料证明支持 PoE。相机通常通过 USB 3.0 连接。

### 6.2 首次联调推荐：网线直连

```text
开发机 RJ45 ── CAT5e/CAT6 ── D3 RJ45
```

机器人出厂网络信息：

```text
D3 IP：10.42.0.101
产品手册所列网关：10.42.0.1
```

直连时开发机有线网卡可手动设置：

```text
IP：10.42.0.201
子网掩码：255.255.255.0
默认网关：留空
DNS：留空
```

验证命令：

```powershell
ping 10.42.0.101
ping -n 50 10.42.0.101
```

浏览器访问：

```text
http://10.42.0.101
```

### 6.3 可以使用局域网开发

```text
开发机 ── Wi-Fi/网线 ── 独立路由器或交换机 ── 网线 ── D3
```

条件：

- 开发机必须能路由到 `10.42.0.101`；
- D3 仍通过 RJ45 网线连接网络设备，手册未说明本体内置 Wi-Fi；
- 路由器 LAN 可使用 `10.42.0.0/24`，且不能给其他设备分配 `10.42.0.101`；
- 建议使用独立路由器、独立交换机或 VLAN，不直接暴露到校园/公司公共网络；
- Wi-Fi 可用于查看、监控和普通开发，但不能承担急停或其他安全功能。

## 7. 刚开箱后的首次连通测试

### 阶段 A：断电检查

- [ ] 检查外壳、关节、接口和线缆是否有运输损伤。
- [ ] 拍照记录整机、铭牌、序列号、接口面板和运输姿态。
- [ ] 核对原配电源、实体急停、XT60电源线和网线。
- [ ] 没有原配电源或实体急停时，不自行上电。
- [ ] 不强行转动未上电关节。

### 阶段 B：可靠固定

- [ ] 使用 4 颗 M6 螺栓通过 `Ø6.6` 底座通孔固定。
- [ ] 复核孔距 `105 × 105 mm` 和底座外形 `120 × 120 mm`。
- [ ] 稳定座已经锚固到工作台/框架，而非自由放置。
- [ ] 四颗螺栓均匀锁紧并采取防松措施。
- [ ] 左右臂下方有软垫或人工支撑，防止断电下坠。

D3 关节无抱闸，断电或急停后可能泄力下坠。未可靠固定时不得进行上电和运动测试。

### 阶段 C：断电接线

推荐顺序：

```text
固定机器人
  → 连接实体急停
  → 连接 XT60 直流电源
  → 连接开发机网线
  → 最后接入交流电
```

- [ ] 核对电源铭牌和机器人交付电压。
- [ ] XT60 红线接正极、黑线接负极。
- [ ] 不带电插拔 XT60。
- [ ] 产品手册标注“未适配”的软件急停口不替代实体急停。
- [ ] 当前无夹爪、无相机，末端接口和 USB 口保持空置。

### 阶段 D：第一次上电

1. 确认机器人和稳定座已经固定。
2. 现场至少一人可立即操作实体急停，建议另一人托住机械臂。
3. 先按下急停，再接通电源组件交流输入。
4. 检查烟雾、焦味、异常发热、打火、剧烈振动和尖锐异响。
5. 解除急停并观察控制器及关节指示灯。
6. 刚上电时不要立即点击复位或回零。

出现任何异常时，立即急停并在人工托住机械臂后切断交流电源。

### 阶段 E：网络和静态状态

1. 设置开发机有线 IPv4 为 `10.42.0.201/24`。
2. 执行 `ping 10.42.0.101`。
3. 访问 `http://10.42.0.101`，不要使用 HTTPS。
4. 确认设备型号为 D3，左右臂和 14 个关节均有状态。
5. 记录控制器、固件、Web 上位机和 SDK 版本。
6. 检查过压、欠压、过温、编码器和通信错误。
7. 左右末端工具保持“无工具/工具编号 0”。

如果上位机页面能打开但显示后端断开，按产品手册检查“关于设备”中的控制器 IP 和后端服务器 IP 是否都与实际访问地址一致。

### 阶段 F：最低速度运动验证

只有前述阶段全部通过后才能进行：

1. 将速度比例设到最低经确认等级，建议第一次不超过约 `5%–10%`。
2. 保持人员托住机械臂，点击复位并观察关节建立力矩时是否跳动。
3. 一次只操作一只手臂；本项目第一阶段只允许右臂发送动作。
4. 先验证拖动模式，确认松手后可以保持姿态。
5. 再按每次 `2°–3°` 的小幅度逐关节点动 J1–J7。
6. 核对界面角度变化、实际方向、零位和软限位。
7. 确认到零位路径不会碰撞工作台、稳定座或另一只手臂后，才低速回零。

软件急停、`task_stop` 和伺服失能不能替代实体急停；伺服失能还可能直接导致手臂下坠。

## 8. 首次测试的通过标准

- [ ] `ping -n 50 10.42.0.101` 无丢包且延迟稳定。
- [ ] `http://10.42.0.101` 可稳定访问。
- [ ] 左右臂与 14 个关节状态均可读取。
- [ ] 无电源、编码器、过温或通信故障码。
- [ ] 未装夹爪时左右工具均为“无工具”。
- [ ] 实体急停可触达，且断电下坠风险已有支撑措施。
- [ ] 右臂拖动模式与单关节低速小幅动作正常。
- [ ] 左臂没有进入项目动作发送路径。
- [ ] 已保存版本、配置、故障码和测试结果。

通过这些项目后，下一步应先编写只读程序，读取连接状态、版本、关节角、法兰位姿和错误码；验证稳定后再接入运动 API、夹爪和腕部相机。

## 9. 需要保留的联调记录

- 机器人、控制器、固件、Web 上位机和 SDK 版本。
- 开发机网络配置及 `ping -n 50` 结果。
- 左右臂状态、14 个关节零位和软限位。
- 工具编号、TCP、工具质量和质心配置。
- 相机型号、序列号、USB拓扑、分辨率、帧率和命名空间。
- 手眼标定文件、夹爪标定文件及其日期。
- 实际发送动作、实际反馈、时间戳、错误码和停止原因。

不要提交账号、令牌、私钥或未脱敏的设备认证信息。
