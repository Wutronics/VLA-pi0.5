## 1. 文档定位与事实边界

本方案用于把“外骨骼遥操作采集 → LeRobot 数据集 → π0.5 训练/部署”的工作拆解为可实施、可验收的阶段。它是硬件到货前的工程设计，不是已完成的接口适配记录。

### 1.1 已知事实

以下内容来自当前项目任务描述，按既定范围实施：

- 第一阶段任务是药盒的抓取与放置（pick and place）。
- 操作对象为 CVTE D3 的右臂。
- 示教方式为外骨骼遥操作，不采用手柄或键盘作为主示教方式。
- 目标工作流需要覆盖 D3 的 LeRobot 单臂适配、数据采集，以及 π0.5 的训练与部署。
- 设备尚未到货，因此尚无实机联调结果。

### 1.2 建议设计

除本节 1.1 外，本文的架构、映射、数据字段、同步策略、阶段计划和验收口径均为建议设计。可先用于选型、开发和风险管理，实机验证后应冻结为接口与数据集规范。

### 1.3 待验证假设（不得视为已确认能力）

- 外骨骼的具体型号、自由度、输出单位、刷新率、SDK/API、许可条件和可导出的时间戳能力均未知。
- D3 右臂的控制接口、可控制关节/末端执行器、状态反馈、限位、控制频率、相机及其标定能力均未知。
- D3 与 LeRobot 的现有兼容性、驱动方式和数据格式适配情况未知。
- π0.5 所需或接受的动作维度、观测字段、动作分块方式、训练入口、推理频率及部署运行时均应以实际版本的官方代码/文档和本地依赖为准。
- 采集采样频率、相机帧率、控制频率和可接受的端到端时延尚未测量；本文不将任何具体数值当作已验证参数。

## 2. 目标、边界与安全原则

### 2.1 第一阶段目标

在固定、受控的工作台上，操作者穿戴外骨骼，通过 D3 右臂完成药盒的接近、抓取、移动、放置与安全退出；将成功、失败和中止过程记录为可追溯的时序数据；在经清洗与切分的数据上完成 π0.5 的离线训练与受控部署验证。

第一阶段优先验证闭环与数据质量，不以泛化到任意药盒、任意场景或连续自主运行作为验收前提。

### 2.2 非目标

- 不假设双臂协作、移动底盘、动态障碍物规避或多任务泛化。
- 不在未完成急停、限位、碰撞/速度约束与人工接管验证前开放自主运动。
- 不以外骨骼的原始人体姿态直接替代机器人的安全控制逻辑。

### 2.3 运行安全基线

建议在联调前由项目负责人和设备供应方确认：

1. 可触达的硬件急停及软件停止路径，并在每次采集前做触发测试。
2. D3 右臂的工作空间、速度/加速度/力（如可用）限制，以及末端夹爪开合范围。
3. 外骨骼失跟踪、断连、越界、通信超时和相机丢帧时的降级策略：停止发送新目标，进入安全保持或供应方定义的安全状态。
4. 清场、药盒固定/可替换、相机支架固定和操作者安全站位。
5. 遥操作始终保留人工中止权；训练策略仅在隔离、低速、受监控条件下上机。

## 3. Leader–Follower 系统架构

外骨骼为 Leader，D3 右臂为 Follower。二者之间必须设置独立的“映射与安全层”，避免将人体侧原始数据直接下发给机器人。

```text
外骨骼（Leader）
  └─ 姿态/关节/手部状态 + 设备时间戳
       │
       ▼
采集端适配器 ──► 时间基准与健康检查 ──► 映射与标定层 ──► 安全与限幅层
       │                                          │                 │
       │                                          │                 ▼
       │                                          │          D3 右臂控制适配器
       │                                          │                 │
       ▼                                          ▼                 ▼
原始遥操作记录                              目标位姿/夹爪命令      D3 状态/反馈
                                                                       │
相机/环境观测 ────────────────────────────────────────────────────────┤
                                                                       ▼
                                                           统一 episode 记录器
                                                                       │
                                                                       ▼
                                                     LeRobot 兼容数据集（候选）
                                                                       │
                                                                       ▼
                                                        π0.5 训练与受控部署
```

### 3.1 组件职责

| 组件 | 建议职责 | 不应假设的内容 |
| --- | --- | --- |
| 外骨骼适配器 | 读取设备状态、连接状态和设备时间戳；保留原始数据 | 具体 SDK 名称、数据格式或输出频率 |
| 时间与健康检查 | 给每条消息保留来源时间、接收时间和序号；检测断连/陈旧数据 | 已具备硬件同步线或统一时钟 |
| 映射与标定层 | 坐标变换、尺度映射、零位偏置、死区、滤波、相对/绝对控制模式 | 人体与机器人自由度一一对应 |
| 安全与限幅层 | 工作空间、速度、加速度、夹爪、失联和急停策略 | D3 支持某种特定安全 API |
| D3 控制适配器 | 将规范化目标转换为 D3 实际控制调用；读取机器人状态 | 已有 LeRobot robot driver |
| episode 记录器 | 将观测、动作、时间戳、标定版本、任务元数据同一事务记录 | π0.5 或 LeRobot 的最终字段名 |
| 训练/部署封装 | 数据校验、切分、训练配置、离线回放、推理和监控 | 特定 π0.5 checkpoint 或动作头格式 |

### 3.2 建议控制模式

优先采用**末端相对位姿增量 + 独立夹爪状态**作为第一种验证模式：外骨骼运动经比例缩放、死区和限幅后，生成 D3 末端相对目标；夹爪根据外骨骼手部信号或经确认的离散输入映射为开、合或保持。该模式通常更容易吸收人体与机器人初始位姿差异。

若 D3 控制接口只接受关节目标，则由 D3 侧官方逆解/控制栈或经验证的本地求解器执行位姿到关节的转换；不得在未验证关节顺序、单位、限位和奇异位姿处理前自行下发关节数组。

## 4. 外骨骼与 D3 动作映射

### 4.1 统一的中间动作表示

建议在 D3 适配器之前定义不绑定任一 SDK 的规范化表示：

```text
teleop_target = {
  sequence_id,
  source_timestamp,
  receive_timestamp,
  mode,                       # 相对位姿 / 绝对位姿 / 保持 / 停止
  ee_delta_or_pose,           # 明确参考坐标系、位置单位与姿态表示
  gripper_command,            # 连续或离散；以设备能力最终确定
  confidence_or_tracking_ok,
  calibration_id
}
```

该表示是设计建议，字段和数据类型应在 D3 API、外骨骼 SDK 和训练栈确认后固化。关键是每一条动作均可追溯到来源、时间和标定版本。

### 4.2 建议映射链路

1. **外骨骼原始状态**：读取躯干/肩/肘/腕或手部相关状态（具体通道由实际设备确定）。
2. **操作者参考系**：以本次会话的中立姿态或外骨骼基座为参考，求相对运动，减少穿戴初始差异。
3. **任务参考系**：经标定转换至工作台/机器人基座约定坐标系。
4. **D3 末端目标**：按轴向尺度、姿态比例、死区、低通/速率限制和工作空间裁剪，生成目标位姿或位姿增量。
5. **夹爪目标**：将经过确认的手部信号映射为开合/保持；应设置防抖、滞回和安全默认态。
6. **D3 命令**：由适配器转换为供应方认可的控制格式，并记录实际发送值与反馈值。

### 4.3 映射参数与验收记录

以下参数不得硬编码在训练数据中；应由配置文件管理，并写入每个 episode 的元数据：

| 参数类别 | 示例 | 验证方法 |
| --- | --- | --- |
| 参考坐标系 | 外骨骼、工作台、D3 基座、末端、相机 | 坐标轴方向检查、固定点复测 |
| 位移尺度 | 各方向缩放比例 | 小幅往返轨迹误差与越界检查 |
| 姿态规则 | 四元数/旋转矩阵/欧拉角、旋转顺序 | 纯轴旋转检查、奇异位姿检查 |
| 零位与偏置 | 穿戴中立姿态、末端初始姿态 | 重复初始化一致性 |
| 速度与限幅 | 最大变化率、死区、滤波系数 | 低速试运行、失跟踪注入 |
| 夹爪规则 | 阈值、滞回、默认态 | 连续开合、防误触测试 |
| 版本标识 | `calibration_id`、配置哈希 | episode 可复现回放 |

## 5. 坐标标定

### 5.1 必需坐标系与命名

建议采用明确且可记录的坐标系命名，而非依赖口头约定：

- `F_robot_base`：D3 机器人基座坐标系。
- `F_ee`：D3 右臂末端执行器/工具坐标系。
- `F_table`：工作台任务坐标系。
- `F_leader`：外骨骼的稳定参考坐标系。
- `F_camera_i`：第 \(i\) 路相机坐标系（若使用）。

实际名称、原点和轴向必须以 D3 文档与实际安装结果为准。

### 5.2 标定流程建议

1. **机械与场景固定**：固定 D3 基座、工作台、相机支架和药盒起止区域；拍照/记录工装版本。
2. **D3 基座—工作台关系**：用供应方允许的方法建立或测量 `F_robot_base → F_table`。
3. **外骨骼中立姿态**：在每位操作者、每个采集会话开始时记录中立姿态与穿戴配置，生成会话级 `calibration_id`。
4. **外骨骼—任务坐标对齐**：让操作者执行少量可观测的轴向/点位动作，确认平移方向、旋转手性及尺度是否正确；必要时估计变换与偏置。
5. **末端工具偏置**：若夹爪或工具改变，重新确认 `F_ee` 到实际抓取点的偏置。
6. **相机标定（如使用）**：确认内参、外参、时间戳来源及与 `F_table` 的关系；相机移动后必须重新标定。
7. **复测与归档**：对固定点、直线、往返轨迹和抓取点进行复测；将结果、误差、操作者、设备序列号（如适用）和配置版本归档。

### 5.3 标定验收建议

标定不以“看起来对齐”为准。建议设定由项目组认可的量化阈值，至少覆盖：

- 坐标轴方向、左右手性与单位一致；
- 重复初始化后轨迹方向一致；
- 工作空间边界处不会因映射放大而越界；
- 外骨骼停止时，D3 目标不持续漂移；
- 重新穿戴/重新启动后可通过同一检查流程恢复一致行为。

具体误差阈值应在 D3 精度、外骨骼精度、药盒尺寸和安全空间确认后制定。

## 6. D3 LeRobot 单臂适配方案

### 6.1 适配原则

将 D3 封装为一个“单右臂机器人适配层”，上层只面对稳定的观测、动作和生命周期接口；所有供应商 SDK 细节留在适配层。是否直接继承 LeRobot 的现成机器人基类、使用自定义驱动，或先以离线数据转换器接入，取决于实机接口和所用 LeRobot 版本，当前不得预设。

### 6.2 建议适配器能力清单

| 能力 | 适配层应提供的语义 | 到货后必须确认 |
| --- | --- | --- |
| 连接与初始化 | 建连、读取设备信息、进入/退出控制态 | SDK 支持的状态机、认证与权限 |
| 右臂状态 | 时间戳、关节/末端/夹爪等实际可读状态 | 字段、单位、坐标系、反馈频率 |
| 右臂命令 | 接收规范化动作并安全下发 | 支持末端还是关节控制、命令频率、插补行为 |
| 安全控制 | 停止、保持、限位/限速配置或其调用入口 | 急停优先级、超时行为、恢复流程 |
| 相机与传感器 | 返回采集可用的观测及其时间信息 | 相机驱动、权限、内外参与时钟 |
| 记录钩子 | 标记 episode 开始/结束/中止、保存元数据 | LeRobot 版本的数据写入 API |
| 自检 | 设备连通、时间单调、状态新鲜度和控制许可 | 所有错误码和健康指标 |

### 6.3 实施顺序

1. 先完成**只读**状态采集和原始日志，不发送运动命令。
2. 在空载、低速、隔离工位下，完成保持、停止、急停及单轴小幅动作验证。
3. 接入相对位姿映射与夹爪命令，人工逐段确认。
4. 将稳定的观测/动作流写入候选 LeRobot 格式，并做离线回放。
5. 仅在上述步骤通过后，开始正式示教采集。

仓库当前为空；以下是建议目录而非现有路径声明：

## 7. 数据采集与时间同步

### 7.1 每个 episode 的建议内容

每次任务尝试均应有独立的 episode 标识，并将以下内容按同一时间线保存：

| 类别 | 建议记录内容 | 目的 |
| --- | --- | --- |
| 任务元数据 | 任务版本、药盒/工装版本、场景布置、成功定义、操作者匿名 ID | 可追溯性与数据分层 |
| 标定元数据 | `calibration_id`、坐标系说明、映射配置哈希 | 重建动作语义 |
| 外骨骼原始流 | 原始通道、来源时间戳、接收时间、追踪/连接状态 | 诊断映射与丢帧 |
