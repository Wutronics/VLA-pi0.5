# D3 右臂七关节小步往返测试报告

- 测试日期：2026-11-24
- 控制器：`10.42.0.101:8090`
- SDK：`carm 1.0.2608191.0.260819`
- 测试对象：`D3_AC_B_r` 右臂
- 测试方式：每个关节从实时反馈位置出发，先 `+1°`、再 `-1°`，每步 4 秒
- 控制模式：`POSITION`
- 控制器速度等级：`1`
- 判定容差：`0.5°`

## 安全前提

测试前由现场操作者确认右臂工作空间已清空、实体急停可触达并全程观察。程序在每条
运动命令前重新读取控制器状态、右臂实时关节位置和 SDK 软限位；仅调用
`move_right_joint()`，没有调用使能、复位、模式切换、夹爪或左臂运动接口。

测试前只读预检结果为 `eligible_for_motion=true`：右臂 `servo=1`、
`fsm_state=POSITION`、`motion_state=1`，七轴速度均为零。左臂处于未使能状态。

## 结论与边界

本次测试证明：交付 SDK 的右臂 J1-J7 索引、实时反馈、软限位检查和低速点到点接口
均可正常使用；七轴均能独立接受小步命令并回到近似起始位置，测试期间未观察到可测的
左臂联动。

产品手册、MuJoCo 模型和外骨骼读取代码对关节的排列均采用从肩到腕的七轴顺序，因此
后续外骨骼适配可先使用候选排列 `exo_indices=[0,1,2,3,4,5,6]`。但是，本次测试没有
测量外骨骼各编码器的物理正方向，不能单独证明 `sign` 全部正确，也不能授权直接启用
无约束的高频 `track_right_joint()`。

下一阶段应使用相对参考姿态、低增益和速度/加速度限幅，逐轴验证外骨骼方向；确认方向
后再启用连续跟随，并将外骨骼原始目标、映射目标和实际发送目标分别写入数据集。
