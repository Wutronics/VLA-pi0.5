数采操作流程

实体按钮操作
  1. 开始前：确认右臂已使能、工作区清空、实体急停可达；检查页面中 D3、外骨骼、相机状态均正常。
  2. 进入跟随：按外骨骼左手红键。系统先捕获外骨骼和 D3 的参考姿态，随后进入 TELEOP。
  3. 开始录制：在 TELEOP 下按蓝键，进入 RECORDING；确认帧数与实际 FPS 持续增长。
  4. 结束本段：再次按蓝键，保存当前 Episode 并保持跟随，可继续下一段。
  5. 停止跟随：按红键。若正在录制，会先保存当前 Episode，再发送安全停止并退出遥操作。
  6. 异常处理：机械臂异常、人员进入工作区或状态灯异常时，立即使用实体急停；不要依赖网页处理紧急情况。

白键在当前 D3 右臂模式不执行自动归零。网页仅监控，关闭网页不会停止机械臂。
